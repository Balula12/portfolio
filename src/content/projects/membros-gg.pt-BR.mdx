## Contexto

Vendedores que usam o GG Checkout para vender cursos precisavam de um lugar pra entregar
o conteúdo. Em vez de redirecionar pra plataformas de terceiros, integramos uma área de
membros nativa — o aluno paga e cai direto no conteúdo, sem fricção.

## Pontos técnicos

A modelagem foi o que mais consumiu tempo. Cada turma tem módulos, cada módulo tem aulas,
cada aluno tem progresso por aula — e tudo isso precisa ser consultável tanto pelo aluno
(o que assistiu) quanto pelo produtor (engagement por aula). Resolvemos com uma combinação
de subcoleções no Firestore + agregações pré-calculadas para queries pesadas.

A customização visual é resolvida com tokens CSS publicados no `<head>` por produtor — o
mesmo bundle JS roda pra todos, mas cada um vê o tema certo.
