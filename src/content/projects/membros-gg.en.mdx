## Context

Sellers using GG Checkout to sell courses needed a place to deliver the content. Instead
of redirecting to third-party platforms, we built a native members area — students pay
and land directly on the content, with no friction.

## Technical notes

Data modeling was the heaviest part. Each class has modules, each module has lessons,
each student has per-lesson progress — and all of it must be queryable both by the student
(what they've watched) and by the producer (engagement per lesson). Solved with a
combination of Firestore subcollections + pre-computed aggregations for heavy queries.

Visual customization is solved with CSS tokens published into `<head>` per producer — the
same JS bundle runs for everyone, but each one sees the correct theme.
